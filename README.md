# Триптих

Небольшой сайт для создания коллажей из трёх фотографий.

## Возможности

- Загрузка нескольких фотографий за раз или перетаскиванием файлов.
- Автоматическая сборка по три: широкий кадр сверху и два кадра снизу.
- Общая подпись на белой полосе над каждым коллажем.
- Предпросмотр и скачивание каждого коллажа в PNG.
- Обработка фотографий локально в браузере: файлы не отправляются на сервер.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

Для публикации на GitHub Pages выберите в настройках репозитория **Settings → Pages → Deploy from a branch → main / (root)**.
